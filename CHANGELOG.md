# Changelog

## 1.0.0 — 2026-08-12

First complete release. Built in 19 reviewed phases.

### Product
- Capture a palm (camera or upload) → an entertainment-only, traditional-palmistry
  reading + a four-panel comic, generated by AI.
- Accounts, saved reading history, per-reading detail pages, delete / export /
  delete-account.

### Engineering
- **Frontend**: FastAPI + Jinja + TypeScript (Vite), a hand-built design system.
- **Auth**: Argon2 password hashing, secure sessions, CSRF on all forms, route
  protection.
- **Computer vision**: safe preprocessing (metadata strip, decompression-bomb
  guard), authoritative quality gate, palm detection (MediaPipe optional, NumPy
  heuristic fallback).
- **AI provider abstraction**: swappable Vision / Text / Image providers with
  deterministic mocks by default and a bounded fallback; Hugging Face + Pollinations
  as real providers.
- **Grounded interpretation**: a structured palmistry knowledge base + deterministic
  rules engine sit between observation and narrative — no free-form fortune-telling,
  no lifespan/medical claims.
- **Pipeline**: observation → interpretation → reading → storyboard → comic, with a
  guaranteed SVG comic fallback.
- **Async jobs**: background job pipeline with a state machine and status polling
  (in-process by default; Redis/RQ optional).
- **Persistence**: durable readings; the raw palm image is never stored.
- **Security**: CSP + security headers, per-user rate limiting, image hardening.
- **Quality**: 68 automated tests on mock providers; GitHub Actions CI (Python
  3.11/3.12 + TypeScript typecheck); gzip + static caching; Docker + docker-compose.
